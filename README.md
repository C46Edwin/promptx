# PROMPTX 2026 – Registration Site

React + TypeScript + Vite + Tailwind CSS.

## Run
```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

## Before you publish
1. Open `src/config/event.ts` and paste the official registration URL into `REGISTRATION_URL`.
2. Put the official QR image at `public/assets/promptx-registration-qr.png`.
3. Add the Vidya and Vidyidh '26 logos (and optional videos) to `public/assets/` (see the README there).

All event details (date, time, venue, etc.) live in `src/config/event.ts`.
